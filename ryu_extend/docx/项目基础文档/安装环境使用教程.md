# SDN IoT 扩展项目安装环境使用教程

## 1. 环境准备

### 1.1 系统要求
- **操作系统**：Ubuntu 20.04 LTS 或更高版本
- **Python**：3.8 或更高版本
- **内存**：至少 4GB
- **磁盘空间**：至少 20GB

### 1.2 安装基础依赖
```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y git curl wget build-essential

# 安装Python相关依赖
sudo apt install -y python3 python3-pip python3-venv
```

## 2. 安装核心组件

### 2.1 安装 Mininet
```bash
# 安装Mininet
sudo apt install -y mininet

# 验证Mininet安装
sudo mn --version
```

### 2.2 安装 Open vSwitch
```bash
# 安装Open vSwitch
sudo apt install -y openvswitch-switch openvswitch-common

# 验证Open vSwitch服务
sudo systemctl status openvswitch-switch
```

### 2.3 安装 Ryu 控制器
```bash
# 方法1：使用pip安装
pip3 install ryu==4.34

# 方法2：从源码安装（推荐用于开发）
git clone https://github.com/faucetsdn/ryu.git
cd ryu
pip3 install .
```

## 3. 项目部署

### 3.1 克隆项目
```bash
git clone <项目仓库地址>
cd ryucontronl2
```

### 3.2 配置虚拟环境（推荐）
```bash
# 在项目根目录执行
chmod +x create_venv.sh
./create_venv.sh

# 激活虚拟环境
source .venv/bin/activate
```

### 3.3 配置启动脚本
启动脚本已自动配置为使用 `.venv` 虚拟环境，无需手动修改。

## 4. 启动项目

### 4.1 一键启动（推荐）
```bash
cd ryu_extend
chmod +x start_project.sh
./start_project.sh deploy
```

### 4.2 手动启动（分步）

#### 4.2.1 启动控制器
```bash
cd ryu_extend
ryu-manager switch/ble_switch_13.py --verbose --ofp-tcp-listen-port 6634
```

#### 4.2.2 启动监控面板
```bash
cd ryu_extend
python3 templates/sdn_dashboard.py
```

#### 4.2.3 启动网络拓扑
```bash
cd ryu_extend
sudo python3 topology/iot_sdn_topology.py
```

## 5. 访问监控面板

启动成功后，在浏览器中访问：
- **普通面板**：http://localhost:5000
- **增强版面板**：http://localhost:5000/enhanced

## 6. 功能测试

### 6.1 测试数据传输

#### 步骤1：在目标主机启动监听
```bash
# 在Mininet CLI中
mininet> xterm h1 h2

# 在h1窗口输入
nc -ul 5005

# 在h2窗口输入
nc -ul 5005
```

#### 步骤2：测试IoT设备
```bash
# 测试iot1 → h1（直接发送到h1）
mininet> iot1 echo "aa:bb:cc:dd:ee:01,temp,25.5" | nc -u 192.168.1.20 5005

# 测试iot2 → h2（直接发送到h2）
mininet> iot2 echo "aa:bb:cc:dd:ee:02,humidity,65.3" | nc -u 192.168.1.21 5005

# 测试iot4 → h1（直接发送到h1）
mininet> iot4 echo "aa:bb:cc:dd:ee:04,pos,(30.12,120.45)" | nc -u 192.168.1.20 5005
```

### 6.2 运行自动化测试
```bash
cd ryu_extend
chmod +x run_tests.sh
./run_tests.sh
```

## 7. 网络拓扑说明

### 7.1 拓扑结构
```
iot1 (192.168.2.10) ─┐
iot2 (192.168.3.11) ───┼── iot3 (NAT网关) ─── s1 ─── s2 ─── h1, h2
iot4 (192.168.4.13) ──┘
```

### 7.2 子网配置
- iot1: 192.168.2.10/24，网关 192.168.2.1
- iot2: 192.168.3.11/24，网关 192.168.3.1
- iot4: 192.168.4.13/24，网关 192.168.4.1
- iot3: 4 个接口，分别连接 s1、iot1、iot2、iot4，启用 iptables NAT

## 8. 故障排除

### 8.1 常见问题

1. **控制器无法启动**
   - 检查Ryu是否正确安装
   - 确认端口6634未被占用
   - 查看控制器日志：`tail -f ryu_extend/logs/controller.log`

2. **Web面板无法访问**
   - 检查5000端口是否开放
   - 确认防火墙设置
   - 查看面板日志：`tail -f ryu_extend/logs/dashboard.log`

3. **网络连通性问题**
   - 使用`sudo mn -c`清理网络
   - 检查OVS服务状态：`sudo systemctl status openvswitch-switch`
   - 验证控制器连接：`ovs-vsctl show | grep Controller`

4. **网关转发问题**
   - 检查iot3的sysctl配置：`sysctl net.ipv4.ip_forward`
   - 验证iot3的4个接口IP配置正确
   - 检查各IoT设备的默认网关指向iot3

### 8.2 调试命令
```bash
# 查看交换机流表
ovs-ofctl dump-flows s1 -O OpenFlow13

# 查看控制器连接
ovs-vsctl show | grep Controller

# 抓包分析
mininet> iot3 xterm
# 然后运行: tcpdump -i any -n 'udp port 5005'
```

## 9. 开发指南

### 9.1 代码结构
```
ryu_extend/
├── switch/                 # 控制器扩展模块
│   ├── ble_switch_13.py    # BLE Mesh交换机控制器
│   ├── extensions/          # OpenFlow扩展字段实现
│   │   ├── app_deployment.py # 应用下发管理器
│   │   ├── app_field.py    # 应用部署扩展字段
│   │   ├── role_switch.py   # 角色切换管理器
│   │   ├── role_field.py   # 角色切换扩展字段
│   │   ├── manager.py      # 扩展字段管理器
│   │   ├── sensor_field.py # 传感器类型字段
│   │   ├── priority_field.py # 设备优先级字段
│   │   └── route_field.py  # 路由选择字段
│   └── test/               # 测试脚本
├── templates/              # Web监控面板
│   ├── sdn_dashboard.py    # 后端服务
│   └── dashboard.html      # 前端界面
├── topology/               # 网络拓扑脚本
│   └── iot_sdn_topology.py # Mininet拓扑定义
├── scripts/                # 辅助脚本
├── docx/                   # 项目文档
├── start_project.sh        # 一键启动脚本
├── run_tests.sh           # 测试脚本
└── core_ctl.sh            # 核心控制脚本
```

### 9.2 添加新功能
1. **添加新的OpenFlow扩展字段**：在 `switch/extensions/` 中创建新的字段类
2. **扩展Web面板**：修改 `templates/sdn_dashboard.py` 和 `templates/dashboard.html`
3. **修改网络拓扑**：编辑 `topology/iot_sdn_topology.py`

### 9.3 新功能使用指南

#### 9.3.1 应用下发功能使用
1. **创建边缘应用**：使用 `AppDeploymentManager` 创建应用
2. **部署应用**：将应用部署到兼容的设备
3. **管理应用**：查看、更新、卸载应用

#### 9.3.2 角色切换功能使用
1. **注册设备**：使用 `DeviceRoleManager` 注册设备
2. **切换角色**：根据需要切换设备模式
3. **识别最优模式**：让系统自动推荐最优模式
