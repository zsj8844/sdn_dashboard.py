# SDN IoT 扩展项目

## 项目概述

这是一个基于 Ryu 控制器的软件定义网络(SDN)物联网(IoT)扩展项目，实现了 BLE Mesh 网络的数据收集、转发和可视化监控功能。项目采用纯 NAT 网关模式，符合真实网络架构。

| 项目名称 | 开源物联网SDN控制器项目 |
|---------|---------------------|
| 当前版本 | v4.5.0 |
| 项目状态 | 所有功能已完成 |

### OpenFlow扩展字段

| 字段名称 | 字段ID | 说明 |
|----------|--------|------|
| SensorType | 1 | 传感器类型（温度、湿度、光照等） |

## 系统架构

### 网络拓扑

```
iot1 (192.168.2.10) ─┐
iot2 (192.168.3.11) ───┼── iot3 (NAT网关) ─── s1 ─── s2 ─── h1, h2
iot4 (192.168.4.13) ──┘
```

### 子网配置

| 设备 | IP 地址 | 说明 |
|------|---------|------|
| iot1 | 192.168.2.10/24 | 温度传感器，网关 192.168.2.1 |
| iot2 | 192.168.3.11/24 | 湿度传感器，网关 192.168.3.1 |
| iot3 | 192.168.2.1 (iot1侧) / 192.168.3.1 (iot2侧) / 192.168.4.1 (iot4侧) / 192.168.1.12 (s1侧) | NAT网关，4个接口 |
| iot4 | 192.168.4.13/24 | 位置传感器，网关 192.168.4.1 |
| h1 | 192.168.1.20/24 | 监控主机 |
| h2 | 192.168.1.21/24 | 监控主机 |
| s1 | 192.168.1.1/24 | 交换机管理IP |
| s2 | 192.168.1.2/24 | 交换机管理IP |
| c0 | 127.0.0.1:6634 | Ryu 控制器 |

### 端口配置

| 端口 | 用途 |
|------|------|
| 6634 | Ryu 控制器监听端口 |
| 5000 | Web 监控面板端口 |
| 5005 | BLE 数据 UDP 端口 |

### 数据流向（两种模式）

**模式A：直接转发（纯网络层，iptables NAT）**

```
IoT设备 → iot3 (NAT网关 iptables转发) → s1 (OpenFlow13) → s2 (OpenFlow13) → h1/h2
```

**模式B：网关处理（应用层智能转发，支持OpenFlow扩展）**

```
IoT设备 → iot3网关(监听5005) → 解析→编码扩展→智能转发 → s1/s2 → h1/h2
```

### 网关转发规则

| 设备地址 | 目标主机 | 说明 |
|----------|----------|------|
| aa:bb:cc:dd:ee:01 | 192.168.1.20 (h1) | iot1 → h1 |
| aa:bb:cc:dd:ee:02 | 192.168.1.21 (h2) | iot2 → h2 |
| aa:bb:cc:dd:ee:04 | 192.168.1.20 (h1) | iot4 → h1 |

| 技术组件 | 用途 |

### 核心文件说明

| 文件 | 说明 |
|------|------|
| `switch/ble_switch_13.py` | 主控制器，集成所有功能：流表管理、拓扑发现、扩展处理、应用下发、角色切换 |
| `switch/extensions/app_deployment.py` | 应用下发管理器，提供边缘应用生命周期管理 |
| `switch/extensions/role_switch.py` | 角色切换管理器，提供设备模式动态切换 |
| `switch/extensions/manager.py` | 扩展字段管理器，创建、序列化（`serialize_fields`/`serialize_to_experimenter`）、反序列化 |
| `templates/sdn_dashboard.py` | Flask Web应用（Jinja2版），提供RESTful API |
| `templates/sdn_dashboard_vue/sdn_dashboard_server/server.py` | Flask API 服务器，生产模式托管 Vue SPA |
| `templates/sdn_dashboard_vue/sdn_dashboard_view/` | Vue 3 + JavaScript 前端 SPA |
| `topology/iot_sdn_topology.py` | Mininet拓扑定义，纯NAT网关模式 |
| `topology/iot_gateway_enhanced.py` | IoT网关增强版，监听5005端口，智能转发数据 |
| `manage.py` | 项目管理脚本：start/stop/status/clean/gateway/help |
