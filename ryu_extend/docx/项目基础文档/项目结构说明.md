## 详细目录说明

### 1. switch/ - 控制器扩展模块

这是项目的核心模块，包含 Ryu 控制器的扩展实现。

```
switch/
├── ble_switch_13.py        # BLE Mesh 交换机控制器（主控制器）
├── extensions/              # OpenFlow 扩展字段实现
│   ├── __init__.py
│   ├── base_field.py       # 扩展字段基类
│   ├── constants.py        # 常量定义
│   ├── demo.py            # 扩展字段演示
│   ├── manager.py         # 扩展字段管理器
│   ├── priority_field.py   # 设备优先级字段
│   ├── route_field.py     # 路由选择字段
│   ├── sensor_field.py    # 传感器类型字段
│   ├── app_field.py       # 应用部署扩展字段
│   ├── role_field.py      # 角色切换扩展字段
│   ├── app_deployment.py  # 应用下发管理器
│   └── role_switch.py     # 角色切换管理器
└── test/                   # 测试脚本
    ├── analyze_packet.py   # 数据包分析工具
    ├── comprehensive_test.py # 综合测试
    ├── full_chain_test.py  # 全链路测试
    ├── gateway_forwarding_test.py # 网关转发测试
    └── test_extensions.py # 扩展字段测试
```

#### 核心文件说明

| 文件 | 说明 |
|------|------|
| `ble_switch_13.py` | 主控制器，继承自 SimpleSwitch13，处理 BLE 数据转发，区分s1和s2交换机，下发流表，集成应用下发和角色切换功能 |
| `extensions/manager.py` | 扩展字段管理器，负责字段的创建、序列化和反序列化 |
| `extensions/sensor_field.py` | 传感器类型字段实现（温度、湿度、光照等） |
| `extensions/priority_field.py` | 设备优先级字段实现（1-5级） |
| `extensions/route_field.py` | 路由选择字段实现（路径A、路径B） |
| `extensions/app_field.py` | 应用部署扩展字段实现 |
| `extensions/role_field.py` | 角色切换扩展字段实现 |
| `extensions/app_deployment.py` | 应用下发管理器，提供边缘应用生命周期管理 |
| `extensions/role_switch.py` | 角色切换管理器，提供设备模式动态切换功能 |

### 3. topology/ - 网络拓扑脚本

包含 Mininet 网络拓扑定义和 IoT 网关模拟器。

```
topology/
├── iot_sdn_topology.py         # Mininet 拓扑定义
└── iot_gateway_enhanced.py     # IoT网关增强版（支持OpenFlow扩展和日志）
```

#### 核心文件说明

| 文件 | 说明 |
|------|------|
| `iot_sdn_topology.py` | 定义网络拓扑，iot1/iot2/iot4连接到iot3网关，iot3连接到s1交换机，采用纯NAT网关模式 |
| `iot_gateway_enhanced.py` | IoT网关增强版，监听5005端口，解析IoT数据，编码OpenFlow扩展，智能转发数据，记录详细日志 |

#### 拓扑结构（v4.3.0）

```
iot1 (192.168.2.10) ─┐
iot2 (192.168.3.11) ───┼── iot3 (IoT网关) ─── s1 (OpenFlow13) ─── s2 (OpenFlow13) ─── h1, h2
iot4 (192.168.4.13) ──┘
```

**子网配置**：
- iot1: 192.168.2.10/24，网关 192.168.2.1
- iot2: 192.168.3.11/24，网关 192.168.3.1
- iot4: 192.168.4.13/24，网关 192.168.4.1
- iot3: 4 个接口，分别连接 s1、iot1、iot2、iot4，启用 iptables NAT 和 IoT网关应用

## 数据流

### 完整数据流向（v4.0.0）

```
1. IoT 设备（iot1/iot2/iot4）发送数据
   ↓ (UDP/5005 直接发送到 h1/h2)
2. iot3 NAT网关通过 iptables 转发数据包
   ↓ (IP转发和NAT)
3. 数据包通过 s1 和 s2 交换机
   ↓
4. s1 交换机捕获数据包
   ↓
5. s1 将数据包发送给 Ryu 控制器（端口 6634）
   ↓
6. ble_switch_13.py 解析数据包，根据DPID区分s1和s2
   ↓
7. 控制器为 s1 和 s2 分别下发流表规则
   ↓
8. 数据包通过 OpenFlow 协议在交换机集群中转发
   ↓
9. 数据包到达目标主机（h1/h2）
   ↓
10. Web 面板通过 API 接收日志并展示
```

## 开发建议

### 添加新的扩展字段

1. 在 `switch/extensions/` 中创建新的字段类
2. 继承 `IoTExtensionField` 基类
3. 实现 `serialize()` 和 `parse()` 方法
4. 在 `manager.py` 中注册新字段

### 添加新的测试

1. 在 `switch/test/` 中创建测试脚本
2. 使用 `run_tests.sh` 运行测试

### 修改拓扑

1. 编辑 `topology/iot_sdn_topology.py`
2. 修改 `net.addLink()` 调用
3. 更新 `ip_map` 配置

## 注意事项

1. **操作系统**：项目主要在 Linux 环境下运行（需要 Mininet）
2. **Python 版本**：Python 3.8+
3. **权限**：运行拓扑需要 sudo 权限
4. **端口占用**：确保 6634、5000、5005 端口未被占用
5. **测试命令**：
   - 方式一（推荐）：IoT设备数据发送到网关对应接口IP（如192.168.2.1），由网关智能转发
   - 方式二：IoT设备数据直接发送到目标主机（h1: 192.168.1.20, h2: 192.168.1.21），通过NAT转发
6. **网关日志**：网关日志保存在`logs/gateway.log`，包含时间戳、接收数据、解析结果、转发信息等
