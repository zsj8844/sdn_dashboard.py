## 二、项目背景与目标

### 2.1 项目背景
本项目是一个基于 Ryu 控制器的软件定义网络（SDN）物联网（IoT）扩展项目，旨在实现 BLE Mesh 网络的数据收集、转发和可视化监控功能。项目采用纯 NAT 网关模式，符合真实网络架构，为物联网场景提供灵活、高效的网络管理解决方案。

### 2.2 项目目标
1. 实现完整的 OpenFlow 1.3 协议支持
2. 提供智能的拓扑管理和流表管理功能
3. 支持物联网设备数据的解析、处理和转发
4. 提供直观的 Web 监控面板
5. 实现可扩展的 OpenFlow 协议扩展机制

## 五、核心技术架构

### 5.1 网络拓扑架构

项目采用纯 NAT 网关模式的网络拓扑结构：

```
iot1 (192.168.2.10) ─┐
iot2 (192.168.3.11) ───┼── iot3 (NAT网关) ─── s1 ─── s2 ─── h1, h2
iot4 (192.168.4.13) ──┘
```

**子网配置**：
- iot1: 192.168.2.10/24，网关 192.168.2.1
- iot2: 192.168.3.11/24，网关 192.168.3.1
- iot4: 192.168.4.13/24，网关 192.168.4.1
- iot3: 4 个接口，分别连接 s1、iot1、iot2、iot4，启用 iptables NAT

### 5.2 数据流向

```
IoT设备 (iot1/iot2/iot4) 
  ↓ (UDP/5005 直接发送到 h1/h2)
iot3 (NAT网关 - iptables转发)
  ↓ (IP转发和NAT)
s1 (OpenFlow13交换机)  ← 控制器下发流表
  ↓ (OpenFlow协议)
s2 (OpenFlow13交换机)  ← 控制器下发流表
  ↓ (UDP/5005)
h1/h2 (监控主机)
```
