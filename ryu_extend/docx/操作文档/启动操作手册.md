## 🔧 详细启动步骤（手动方式）

### 步骤1：环境准备

```bash
# 进入项目目录
cd /home/zhang/桌面/ryucontronl2/ryu_extend

# 检查必要权限
sudo -v

# 创建日志目录
mkdir -p logs

# 设置脚本执行权限
chmod +x start_project.sh
chmod +x core_ctl.sh
chmod +x run_tests.sh
```

### 步骤2：清理历史环境

```bash
# 清理Mininet残留
sudo mn -c

# 杀掉占用端口的进程
sudo lsof -i:6634 -t | xargs -r sudo kill -9 2>/dev/null || true
sudo lsof -i:5000 -t | xargs -r sudo kill -9 2>/dev/null || true

# 清理OVS网桥
sudo ovs-vsctl del-br s1 2>/dev/null || true
sudo ovs-vsctl del-br s2 2>/dev/null || true
```

### 步骤3：启动控制器

```bash
# 使用Ryu管理器启动控制器
cd /home/zhang/桌面/ryucontronl2/ryu_extend
ryu-manager switch/ble_switch_13.py --verbose --ofp-tcp-listen-port 6634
```

**预期输出**：
```
loading app switch/ble_switch_13.py
loading app ryu.controller.ofp_handler
instantiating app switch/ble_switch_13.py of BLESwitch13
instantiating app ryu.controller.ofp_handler of OFPHandler
```

### 步骤4：启动Web面板

```bash
# 启动Flask Web服务（另一个终端）
cd /home/zhang/桌面/ryucontronl2/ryu_extend
python3 templates/sdn_dashboard.py
```

**预期输出**：

**访问地址**：

**预期结果**：

3. **控制器日志**：看到PacketIn消息和流表下发记录
4. **Web面板**：显示完整的数据传输链路日志

2. **控制器日志**：看到PacketIn消息和流表下发记录
3. **Web面板**：显示完整的数据传输链路日志

```bash
# 检查控制器端口
echo "控制器端口(6634):"

echo "Mininet进程:"

```

### 2. 交换机状态检查

```bash
# 查看交换机信息
echo "=== 交换机状态 ==="

echo "控制器连接状态:"

sudo ovs-vsctl get-controller s2

# 查看流表
echo "流表统计:"
echo "s1流表数量: $(sudo ovs-ofctl dump-flows s1 -O OpenFlow13 | wc -l)"
```

```bash
# 检查iptables NAT规则
mininet> iot3 iptables -t nat -L -n -v
```

```bash

# 控制器日志检查
```

## 🚨 常见启动问题及解决方案

### 问题1：端口被占用

**现象**：
```
ryu-manager: error: [Errno 98] Address already in use
```

**解决方案**：
```bash
# 查找占用进程
sudo lsof -i:6634

# 杀掉占用进程
sudo kill -9 $(sudo lsof -t -i:6634)

# 或使用一键清理
./start_project.sh clean
```

### 问题2：权限不足

**现象**：
```
Permission denied: '/var/run/openvswitch'
```

**解决方案**：
```bash
# 确保以sudo权限运行
sudo python3 topology/iot_sdn_topology.py

# 或检查用户组
groups | grep docker
sudo usermod -aG docker $USER
```

### 问题3：Python环境问题

**现象**：
```
ModuleNotFoundError: No module named 'ryu'
```

**解决方案**：
```bash
# 激活正确的conda环境
source /home/zhang/miniconda3/bin/activate ryu-env

# 或安装缺失的包
pip install ryu==4.34
```

### 问题4：网络接口冲突

**现象**：
```
RTNETLINK answers: File exists
```

**解决方案**：
```bash
# 清理网络接口
sudo ip link delete s1 2>/dev/null || true
sudo ip link delete s2 2>/dev/null || true

# 重新启动
./start_project.sh deploy
```

### 问题5：控制器连接失败

**现象**：
```
could not connect to controller
```

**解决方案**：
```bash
# 检查控制器是否运行
sudo lsof -i:6634

# 重新启动控制器
sudo pkill -f "ryu.cmd.manager"
ryu-manager switch/ble_switch_13.py --ofp-tcp-listen-port 6634

# 重新设置交换机控制器
sudo ovs-vsctl set-controller s1 tcp:127.0.0.1:6634
```

### 问题6：网关无法转发数据

**现象**：IoT设备发送数据后，目标主机无反应

**解决方案**：
```bash
# 1. 检查iptables NAT规则
mininet> iot3 iptables -t nat -L -n -v

# 2. 检查IP转发是否启用
mininet> iot3 sysctl net.ipv4.ip_forward
# 应该返回 net.ipv4.ip_forward = 1

# 3. 确认数据直接发送到目标主机（不是到网关）
# 正确命令：
mininet> iot1 echo "aa:bb:cc:dd:ee:01,temp,25.5" | nc -u 192.168.1.20 5005

# 4. 抓包分析
mininet> iot3 xterm
# 然后运行：tcpdump -i any -n 'udp port 5005'
```

## 📈 启动性能优化

### 1. 并行启动优化

```bash
#!/bin/bash
# parallel_start.sh

cd /home/zhang/桌面/ryucontronl/ryu_extend

echo "⚡ 并行启动所有服务..."

# 并行启动控制器和Web面板
{
    ryu-manager switch/ble_switch_13.py --ofp-tcp-listen-port 6634 \
        > logs/controller.log 2>&1 &
    echo $! > logs/controller.pid
} &

{
    python3 templates/sdn_dashboard.py \
        > logs/dashboard.log 2>&1 &
    echo $! > logs/dashboard.pid
} &

# 等待基础服务启动
wait
sleep 5

# 启动网络拓扑
sudo python3 topology/iot_sdn_topology.py > logs/topology.log 2>&1 &
echo $! > logs/topology.pid

echo "✅ 所有服务启动完成！"
```
