# SDN IoT 控制器增强版使用文档

## 1. 快速开始
1
### 1.1 系统要求
- Linux 操作系统 (推荐 Ubuntu 20.04+)
- Python 3.8 或更高版本
- 至少 4GB RAM
- 至少 20GB 可用硬盘空间

### 1.2 安装依赖

```bash
# 使用自动脚本创建虚拟环境并安装依赖
chmod +x create_venv.sh
./create_venv.sh

# 激活虚拟环境
source .venv/bin/activate
```

### 1.3 启动系统

#### 步骤 1: 启动 Web 面板
```bash
cd ryu_extend
python templates/sdn_dashboard.py
```

#### 步骤 2: 启动 Ryu 控制器
```bash
cd ryu_extend
ryu-manager switch/ble_switch_13.py --verbose --ofp-tcp-listen-port 6634
```

#### 步骤 3: 启动 Mininet 拓扑 (推荐)
```bash
cd ryu_extend
sudo python topology/iot_sdn_topology.py
```

### 1.4 访问 Web 面板
- 普通面板: http://localhost:5000
- 增强版面板: http://localhost:5000/enhanced

## 2. Web 面板使用指南

### 2.1 系统概览
系统概览页面展示:
- 交换机在线状态
- BLE 节点在线状态
- 拓扑链接数量
- 系统状态
- 上次更新时间

### 2.2 拓扑可视化
拓扑可视化页面展示:
- 网络拓扑图 (使用 D3.js 绘制)
- 交换机、主机和链接的可视化
- 拓扑信息统计

**操作说明**:
1. 点击"拓扑可视化"标签页
2. 查看网络拓扑结构
3. 观察节点和链接的实时状态

### 2.3 流表管理
流表管理页面允许:
- 添加新的流表
- 清空流表
- 查看当前流表

#### 添加流表
1. 选择目标交换机 (s1 或 s2)
2. 输入流表 ID (默认 0)
3. 输入优先级 (默认 10)
4. 输入匹配条件，例如:
   - `eth_type=0x0800,ipv4_dst=192.168.1.20`
   - `in_port=1,eth_dst=00:00:00:00:00:01`
5. 输入动作，例如:
   - `output:2` (输出到端口 2)
   - `drop` (丢弃数据包)
6. 点击"添加流表"按钮

#### 清空流表
1. 选择目标交换机
2. 输入要清空的流表 ID (可选，留空则清空所有)
3. 点击"清空流表"按钮
4. 确认操作

### 2.4 统计数据
统计数据页面展示:
- 端口统计 (收发数据包数、字节数等)
- 流表统计 (匹配次数、字节数等)
- 流表表统计 (活跃流表数、查询次数等)

**查看统计**:
1. 点击"统计数据"标签页
2. 查看各类型的统计信息
3. 统计数据每 10 秒自动更新

### 2.5 日志监控
日志监控页面展示:
- 网关数据传输日志
- 交换机 s1 数据传输日志
- 交换机 s2 数据传输日志

### 2.6 边缘应用管理
边缘应用管理功能允许您：
- 创建和管理边缘应用
- 将应用部署到设备
- 从设备卸载应用
- 查看应用部署状态

#### 创建边缘应用
1. 准备应用代码（Python脚本或其他可执行代码）
2. 调用控制器API创建应用：
   - 指定应用ID（唯一标识）
   - 指定应用名称
   - 选择应用类型（1=数据过滤，2=AI推理，3=数据聚合，4=自定义）
   - 提供应用代码
3. 系统会自动计算应用代码的SHA256校验和

#### 部署应用到设备
1. 确保应用已创建
2. 调用部署API，指定：
   - 应用ID
   - 目标设备ID
3. 系统会记录部署操作并更新应用状态

#### 卸载应用
1. 调用卸载API，指定：
   - 应用ID
   - 设备ID
2. 系统会从设备中移除应用
3. 如果应用不再部署在任何设备上，状态会更新为"已停止"

### 2.7 设备角色管理
设备角色管理功能允许您：
- 注册设备并设置初始角色
- 动态切换设备角色
- 识别设备最优角色
- 查看设备可用角色

#### 注册设备
1. 调用注册API，指定：
   - 设备ID（唯一标识）
   - 设备名称
   - 初始模式（1=纯转发，2=计算混合，3=物联网网关）
   - 设备能力（可选，包括CPU核心数、内存、GPU支持等）

#### 切换设备角色
1. 调用切换API，指定：
   - 设备ID
   - 目标模式
   - 是否强制切换（可选，默认false）
2. 系统会验证设备是否支持目标模式
3. 如果验证通过，切换设备模式并记录操作

#### 识别设备最优模式
1. 调用识别API，指定：
   - 设备ID
   - 流量模式（可选，包括流量量、流量类型）
   - 资源使用情况（可选，包括CPU使用率、内存使用率）
2. 系统会根据输入信息推荐最优模式

#### 获取流表
```http
GET /api/flows?dpid=1
```

#### 添加流表
```http
POST /api/flows
Content-Type: application/json

{
  "dpid": 1,
  "table_id": 0,
  "priority": 100,
  "match": "eth_type=0x0800,ipv4_dst=192.168.1.20",

}
```

#### 删除流表
```http
DELETE /api/flows
Content-Type: application/json

{
  "dpid": 1,
  "table_id": 0
}
```

## 4. 最佳实践

### 4.1 流表设计
- 使用合理的优先级 (高优先级流表先匹配)
- 合理使用 idle_timeout 和 hard_timeout
- 避免过多的流表，影响性能

### 4.2 性能优化
- 定期清理过期的流表
- 合理设置统计收集间隔
- 使用多级流表进行流量分类

### 4.3 安全建议
- 限制控制器的访问 IP
- 使用防火墙保护 6633 和 5000 端口
- 定期检查日志，发现异常行为

## 5. 故障排查

### 5.1 控制器无法启动
**症状**: 控制器启动失败
**解决方案**:
1. 检查 Python 依赖是否正确安装
2. 检查端口 6633 是否被占用
3. 查看错误日志

### 5.2 交换机无法连接
**症状**: 交换机无法连接到控制器
**解决方案**:
1. 检查控制器 IP 地址是否正确
2. 检查防火墙设置
3. 确认交换机和控制器在同一网络

### 5.3 拓扑不显示
**症状**: Web 面板拓扑页面为空
**解决方案**:
1. 确认交换机已连接到控制器
2. 等待 10-15 秒让 LLDP 完成发现
3. 检查控制器日志

### 5.4 统计数据不更新
**症状**: 统计页面数据不变化
**解决方案**:
1. 确认有网络流量经过交换机
2. 等待 10 秒让统计收集线程运行
3. 检查控制器和 Web 面板的连接

## 6. 常见问题

**Q: 如何重置系统状态?**
A: 访问普通面板，点击"清空数据"按钮，或调用 `/api/clear-data` API

**Q: 支持哪些 OpenFlow 版本?**
A: 目前仅支持 OpenFlow 1.3

**Q: 如何修改统计收集间隔?**
A: 修改 `ble_switch_13.py` 中的 `self.stats_interval` 值

**Q: 可以添加更多交换机吗?**
A: 可以，使用 Mininet 创建更多交换机，控制器会自动发现

**Q: 如何查看详细的调试日志?**
A: 启动控制器时添加 `--verbose` 参数: `ryu-manager --verbose ble_switch_13.py`
