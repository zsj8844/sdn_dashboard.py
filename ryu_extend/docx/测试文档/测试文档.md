## 故障排查

### 常见问题

1. **iptables NAT配置失败**
   - 检查iptables规则：`mininet> iot3 iptables -t nat -L -n -v`
   - 检查IP转发：`mininet> iot3 sysctl net.ipv4.ip_forward`

2. **IoT设备无法发送数据**
   - 检查网络连通性：`mininet> iot1 ping -c 1 192.168.1.20`
   - 确认数据发送到正确的目标主机（不是网关）

3. **数据转发失败**
   - 检查交换机流表：`mininet> sh ovs-ofctl dump-flows s1 -O OpenFlow13`
   - 检查控制器日志

4. **Web面板无日志**
   - 检查控制器是否正确推送日志
   - 检查Web面板是否正常运行

### 调试命令

- 查看控制器日志：在控制器终端查看
- 查看交换机流表：`ovs-ofctl dump-flows s1 -O OpenFlow13`
- 检查iptables规则：`mininet> iot3 iptables -t nat -L -n -v`
- 抓包分析：`mininet> iot3 xterm` 然后运行 `tcpdump -i any -n 'udp port 5005'`
