## 1 引言

### 1.1 软件概述
SDN IoT控制器增强版系统是一个基于Ryu控制器的软件定义网络（SDN）物联网（IoT）扩展系统，旨在实现物联网设备的数据收集、转发和可视化监控功能。系统采用纯NAT网关模式，符合真实网络架构，为物联网场景提供灵活、高效的网络管理解决方案。

### 1.2 主要功能
- 系统概览：实时监控系统运行状态
- 拓扑可视化：基于LLDP自动发现并可视化网络拓扑
- 流表管理：手动添加、查看和清空流表规则
- 统计数据：查看端口统计、流表统计信息
- 日志监控：实时查看网关和交换机的数据传输日志
- 边缘应用管理：创建、部署、管理边缘应用
- 设备角色管理：注册设备、切换设备模式（纯转发/计算混合/物联网网关）

## 3 安装与部署

### 3.1 环境准备

#### 3.1.1 安装Python
1. 访问Python官方网站（https://www.python.org/）
2. 下载Python 3.8或更高版本安装包
3. 运行安装程序，勾选"Add Python to PATH"选项
4. 完成安装后，在命令行输入`python --version`验证安装

#### 3.1.2 安装Mininet（Linux环境）
```bash
sudo apt-get update
sudo apt-get install mininet
```

#### 3.1.3 安装Open vSwitch
```bash
sudo apt-get install openvswitch-switch
```

#### 3.1.4 安装Python依赖
```bash
# 使用自动脚本创建虚拟环境并安装依赖
chmod +x create_venv.sh
./create_venv.sh

# 激活虚拟环境
source .venv/bin/activate
```

### 3.2 项目部署
1. 将项目代码复制到本地目录
2. 进入项目目录：`cd ryu_extend`
3. 确认目录结构完整

### 3.3 启动系统

#### 3.3.1 使用一键启动脚本（推荐）
在项目根目录执行一键启动脚本：

```bash
# 确保虚拟环境已激活
source .venv/bin/activate

# 执行启动脚本
cd ryu_extend
./start_project.sh deploy
```

脚本将自动完成以下操作：
- 初始化运行环境
- 清理环境残留
- 验证虚拟环境
- 启动SDN控制器
- 启动Web监控面板
- 检查服务状态

#### 3.3.2 手动启动Mininet网络拓扑
脚本启动完成后，需要手动启动Mininet拓扑。打开一个新的终端窗口，执行：

```bash
cd ryu_extend/topology
sudo python iot_sdn_topology.py
```

【此处插入Mininet启动截图】

#### 3.3.3 其他脚本命令
- **完整部署（含测试）**：`./start_project.sh full`
- **清理环境**：`./start_project.sh clean`
- **查看帮助**：`./start_project.sh help`

## 4 系统功能操作指南

**注意**：以下功能操作均基于**增强版面板**（`http://localhost:5000/enhanced`）。

### 4.1 系统概览

#### 4.1.1 功能说明
系统概览页面实时显示系统的运行状态，包括交换机在线数量、BLE节点在线数量、拓扑链接数、系统状态和上次更新时间等关键指标。

#### 4.1.2 操作步骤
1. 登录Web监控面板后，默认显示"系统概览"标签页
2. 查看顶部状态栏的关键指标
3. 查看"系统概览"区域的详细信息
4. 查看"控制器与交换机连接状态"区域
5. 查看"BLE节点状态"区域

【此处插入系统概览截图】

### 4.2 拓扑可视化

#### 4.2.1 功能说明
拓扑可视化页面基于LLDP（链路层发现协议）自动发现网络设备和链路，并以图形化方式展示网络拓扑结构。

#### 4.2.2 操作步骤
1. 点击顶部导航栏的"拓扑可视化"标签
2. 在"网络拓扑"区域查看可视化的网络拓扑图
3. 在"拓扑信息"区域查看拓扑的详细数据（交换机、链接、主机数量等）

【此处插入拓扑可视化截图】

#### 4.2.3 拓扑结构说明
系统采用传统网关模式的网络拓扑：
- iot1、iot2、iot4：物联网设备（温度传感器、湿度传感器、位置传感器）
- iot3：物联网网关（NAT网关）
- s1、s2：OpenFlow交换机
- h1、h2：监控主机

拓扑连接关系：
```
iot1 ─┐
iot2 ───┼── iot3 (网关) ─── s1 ─── s2 ─── h1, h2
iot4 ──┘
```

### 4.3 流表管理

#### 4.3.1 功能说明
流表管理功能支持手动添加流表规则、查看交换机流表、清空流表等操作，实现对网络流量的精细控制。

#### 4.3.2 查看流表
1. 点击顶部导航栏的"流表管理"标签
2. 在"交换机流表（s1）"区域查看s1交换机的流表规则
3. 在"交换机流表（s2）"区域查看s2交换机的流表规则

【此处插入流表信息截图】

#### 4.3.3 添加流表
1. 在"添加流表"区域填写流表信息：
   - 选择交换机（s1或s2）
   - 输入流表ID（默认0）
   - 输入优先级（默认10）
   - 输入匹配条件（如：eth_type=0x0800,ipv4_dst=192.168.1.20）
   - 输入动作（如：output:2）
2. 点击"添加流表"按钮

【此处插入添加流表截图】

#### 4.3.4 清空流表
1. 在"添加流表"区域点击"清空流表"按钮
2. 确认清空操作

## 5 API接口说明

### 5.1 概述
系统提供RESTful API接口，支持获取拓扑信息、统计数据、流表信息等。

### 5.2 基础URL
`http://localhost:5000`

### 5.3 API接口列表

#### 5.3.1 获取拓扑信息
- **接口**：`GET /api/topology`
- **说明**：获取当前网络拓扑信息
- **返回示例**：
```json
{
  "switches": [1, 2],
  "hosts": [...],
  "links": [...]
}
```

#### 5.3.2 获取统计信息
- **接口**：`GET /api/stats`
- **说明**：获取交换机端口统计和流表统计
- **返回示例**：
```json
{
  "port_stats": {...},
  "flow_stats": {...},
  "table_stats": {...}
}
```

#### 5.3.3 获取系统状态
- **接口**：`GET /api/status`
- **说明**：获取系统运行状态
- **返回示例**：
```json
{
  "switches_online": 2,
  "system_status": "正常",
  "last_update": "2026-03-07 22:00:00"
}
```

#### 5.3.4 健康检查
- **接口**：`GET /health`
- **说明**：检查系统健康状态
- **返回示例**：
```json
{
  "status": "healthy",
  "timestamp": "2026-03-07 22:00:00",
  "gateway_logs_count": 10,
  "nodes_online": 4
}
```

## 6 常见问题与故障排除

### 6.1 拓扑未显示
**问题**：Web面板中拓扑可视化区域显示"等待拓扑发现..."
**解决方案**：
1. 确认Ryu控制器已启动并使用`--observe-links`参数
2. 确认Mininet网络已启动
3. 等待30秒让LLDP协议完成设备发现
4. 刷新Web页面

### 6.2 数据无法传输
**问题**：物联网设备发送的数据无法到达监控主机
**解决方案**：
1. 确认iot3网关的NAT配置正确
2. 确认控制器已下发正确的流表规则
3. 检查IP地址和端口号是否正确
4. 在Mininet中使用`pingall`测试网络连通性

### 6.3 控制器启动失败
**问题**：执行`ryu-manager`命令时报错
**解决方案**：
1. 确认已正确安装ryu：`pip install ryu`
2. 确认Python版本为3.8或更高
3. 检查端口6633是否被占用
4. 查看错误日志，根据提示修复问题

### 6.4 Mininet启动失败
**问题**：执行`sudo python iot_sdn_topology.py`时报错
**解决方案**：
1. 确认使用sudo权限执行
2. 确认已安装Mininet和Open vSwitch
3. 检查是否有残留的Mininet进程，执行`sudo mn -c`清理
4. 查看错误日志，根据提示修复问题

### 6.5 Web面板无法访问
**问题**：浏览器访问`http://localhost:5000`无法打开
**解决方案**：
1. 确认`sdn_dashboard.py`已启动
2. 确认端口5000未被占用
3. 检查防火墙设置
4. 尝试使用`http://127.0.0.1:5000`访问

### 6.6 边缘应用管理或设备角色管理功能无法使用
**问题**：点击"边缘应用管理"或"设备角色管理"标签无响应
**解决方案**：
1. 确认Web面板已正确启动
2. 刷新浏览器页面
3. 检查浏览器控制台是否有JavaScript错误
4. 确认Python环境中已导入相关扩展模块
