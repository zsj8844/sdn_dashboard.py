# SDN IoT 扩展项目

## 项目概述

这是一个基于 Ryu 控制器的软件定义网络（SDN）物联网（IoT）实验原型。IoT 设备经 iot3 网关进入 SDN 域，控制器负责主机发现、路由决策与 OpenFlow 1.3 流表下发，并通过 Experimenter 字段携带传感器类型、优先级、路由选择等业务元数据。项目提供 Flask API 与 Vue 3 可视化面板。

iot3 网关承担三层转发（`net.ipv4.ip_forward=1`）与应用层 UDP 收数/转发，**不使用 iptables NAT**；跨子网流量的转发路径由控制器流表决定。

| 项目名称 | SDN IoT 实验项目 |
|---------|-----------------|
| 当前版本 | v4.5.2 |
| 项目状态 | 实验原型：基础转发与面板可用，BLE 接入与扩展数据面未完成 |

### OpenFlow 扩展字段

| 字段名称 | 字段ID | 说明 |
|----------|--------|------|
| SensorType | 1 | 传感器类型（温度、湿度、光照等） |
| DevicePriority | 2 | 设备优先级（1-5 级） |
| RouteSelect | 3 | 路由选择（route_a / route_b） |
| AppDeployment | 4 | 应用部署字段（应用ID、动作、版本） |
| RoleSwitch | 5 | 角色切换字段（目标模式、是否强制） |

字段采用 TLV 编码：`type(1B) + length(1B) + reserved(2B) + payload`，长度字段覆盖整个字段。

### 网络拓扑

```
iot1 (192.168.2.10) ─┐
iot2 (192.168.3.11) ──┼── iot3 网关 ─── s1 ─── s2 ─── h1 (192.168.1.20)
iot4 (192.168.4.13) ──┘                         └────── h2 (192.168.1.21)
```

| 设备 | IP 地址 | 说明 |
|------|---------|------|
| iot1 | 192.168.2.10/24 | 温度传感器节点，网关 192.168.2.1 |
| iot2 | 192.168.3.11/24 | 湿度传感器节点，网关 192.168.3.1 |
| iot3 | 192.168.2.1 / 192.168.3.1 / 192.168.4.1 / 192.168.1.12 | 网关，4 个接口，开启 IP 转发 |

### 端口配置

| 端口 | 用途 |
|------|------|
| 6634 | Ryu 控制器监听端口（OpenFlow 1.3） |
| 5000 | Flask API / 监控面板 |
| 5173 | Vue 开发服务器（`/api` 代理到 5000） |
| 5005 | IoT 数据 UDP 端口 |
| 16634 | 控制器内部控制 HTTP，仅监听 127.0.0.1 |
| 6650 | 网关“上报扩展信息”目标端口，当前控制器未监听 |

### 数据流向

**方式一：直接转发（不经过网关应用层处理）**

```
IoT设备 → iot3（三层 IP 转发） → s1 → s2 → h1/h2
                                   ↑
                            控制器预装 IPv4 流表
```

**方式二：网关处理（应用层解析 + 扩展编码 + 转发）**

```
IoT设备 → iot3:5005（接收/解析/编码） → s1 → s2 → h1/h2
                    │
                    └─ 扩展信息尝试发往 127.0.0.1:6650（无接收端）
```

> 主动流表（priority=100）生效后，IPv4 数据不再触发 Packet-In，控制器不会持续看到 BLE 数据；扩展字段链路仅在首包或流表清空后运行。

### 网关转发规则

| BLE 地址 | 目标主机 | 说明 |
|----------|----------|------|
| aa:bb:cc:dd:ee:01 | 192.168.1.20 (h1) | iot1 → h1 |
| aa:bb:cc:dd:ee:02 | 192.168.1.21 (h2) | iot2 → h2 |
| aa:bb:cc:dd:ee:04 | 192.168.1.20 (h1) | iot4 → h1 |
