## 1. OpenFlow 1.3 协议支持

### 1.1 流表下发

**实现位置**: `ble_switch_13.py:add_flow()`

```python
def add_flow(self, datapath, priority, match, actions,
             idle_timeout=0, hard_timeout=0, table_id=0):
    ofproto = datapath.ofproto
    parser = datapath.ofproto_parser

    inst = [parser.OFPInstructionActions(ofproto.OFPIT_APPLY_ACTIONS, actions)]
    mod = parser.OFPFlowMod(
        datapath=datapath, table_id=table_id, priority=priority,
        match=match, instructions=inst,
        idle_timeout=idle_timeout, hard_timeout=hard_timeout
    )
    datapath.send_msg(mod)
```

**参数说明**:
- `datapath`: 交换机数据路径对象
- `priority`: 流表优先级（0-65535）
- `match`: OFPMatch 匹配条件
- `actions`: 动作列表
- `idle_timeout` / `hard_timeout`: 超时时间（秒）
- `table_id`: 流表ID（0-254）

### 1.2 流表删除

**实现位置**: `ble_switch_13.py:delete_flow()`

```python
def delete_flow(self, datapath, match=None, priority=None, table_id=0):
    ofproto = datapath.ofproto
    parser = datapath.ofproto_parser

    if match is None:
        match = parser.OFPMatch()

    mod = parser.OFPFlowMod(
        datapath=datapath, table_id=table_id,
        priority=priority if priority is not None else ofproto.OFP_DEFAULT_PRIORITY,
        match=match, command=ofproto.OFPFC_DELETE,
        out_port=ofproto.OFPP_ANY, out_group=ofproto.OFPG_ANY
    )
    datapath.send_msg(mod)
```

### 1.3 流表修改

**实现位置**: `ble_switch_13.py:modify_flow()`

使用 `command=ofproto.OFPFC_MODIFY` 修改现有流表规则。

### 1.4 统计收集

**实现位置**: `ble_switch_13.py:_stats_collector()`

```python
def _stats_collector(self):
    while True:
        hub.sleep(self.stats_interval)
        for dpid, datapath in list(self.topology['switches'].items()):
            try:
                self.request_port_stats(datapath)    # 端口统计
                self.request_flow_stats(datapath)    # 流表统计
                self.request_table_stats(datapath)   # 表统计
            except Exception as e:
                self.logger.warning(f"收集交换机 {dpid} 统计失败: {e}")
```

默认收集间隔: 10 秒。

## 2. 拓扑管理

### 2.1 自动拓扑发现（LLDP）

**LLDP 发送线程** (`ble_switch_13.py:_lldp_sender()`):
- 定期从每个交换机端口发送 LLDP 数据包
- 默认发送间隔: 5 秒

**LLDP 数据包结构**:
- Chassis ID: 交换机 MAC 地址
- Port ID: 端口号
- TTL: 10 秒
- System Name: `switch-{dpid}`

**LLDP 处理** (`ble_switch_13.py:_handle_lldp_packet()`):

```python
def _handle_lldp_packet(self, dpid, in_port, pkt):
    lldp_pkt = pkt.get_protocol(lldp.lldp)
    if not lldp_pkt:
        return

    chassis_id = port_id = system_name = None
    for tlv in lldp_pkt.tlvs:
        if tlv.tlv_type == lldp.lldp.LLDP_TLV_CHASSIS_ID:
            chassis_id = tlv.chassis_id
        elif tlv.tlv_type == lldp.lldp.LLDP_TLV_PORT_ID:
            port_id = tlv.port_id
        elif tlv.tlv_type == lldp.lldp.LLDP_TLV_SYSTEM_NAME:
            system_name = tlv.system_name

    if chassis_id and port_id and system_name:
        src_switch = system_name.decode('utf-8')
        src_port = int(port_id.decode('utf-8'))
        dst_switch = f'switch-{dpid}'
        dst_port = in_port
        self._add_link(src_switch, src_port, dst_switch, dst_port)
```

### 2.2 拓扑可视化

使用 D3.js v7 在 Web 面板中绘制 SVG 图形：
- **交换机节点**: 蓝色圆形
- **主机节点**: 绿色圆形
- **链接**: 蓝色线条
- 支持节点拖拽和缩放

- 支持 Table ID 0-254

## 4. 协议扩展功能

### 4.1 扩展字段类型

基于 OpenFlow Experimenter 机制扩展协议字段：

| 字段ID | 类名 | 说明 |
|--------|------|------|
| 1 | SensorTypeField | 传感器类型匹配 |
| 2 | DevicePriorityField | 设备优先级 |
| 3 | RouteSelectionField | 路由选择 |
| 4 | AppDeploymentField | 应用部署字段 |
| 5 | RoleSwitchField | 角色切换字段 |

### 4.2 扩展管理器

**实现位置**: `switch/extensions/manager.py`

```python
class IoTExtensionManager:
    def __init__(self):
        self.field_classes = {
            1: SensorTypeField,
            2: DevicePriorityField,
            3: RouteSelectionField,
            4: AppDeploymentField,
            5: RoleSwitchField
        }

    def create_iot_extension(self, **kwargs):
        fields = []
        if 'sensor_type' in kwargs:
            fields.append(SensorTypeField(kwargs['sensor_type']))
        if 'device_priority' in kwargs:
            fields.append(DevicePriorityField(kwargs['device_priority']))
        if 'route_selection' in kwargs:
            fields.append(RouteSelectionField(kwargs['route_selection']))
        if 'app_deployment' in kwargs:
            fields.append(AppDeploymentField(kwargs['app_deployment']))
        if 'role_switch' in kwargs:
            fields.append(RoleSwitchField(kwargs['role_switch']))
        return IoTExtensionMessage(fields=fields)
```

### 4.3 扩展处理流程

**实现位置**: `ble_switch_13.py:process_iot_extension()`

```python
def process_iot_extension(self, msg):
    if not self.extension_enabled:
        return None
    try:
        extension = self.extension_manager.parse_message(msg)
        return self.extension_manager.get_field_dict(extension)
    except Exception as e:
        self.logger.warning(f"处理IoT扩展失败: {e}")
        return None
```

### 4.4 多协议兼容（功能降级）

当扩展功能不可用时，自动降级到标准 OpenFlow 1.3 协议：

```python
EXTENSIONS_AVAILABLE = False
try:
    from extensions.manager import IoTExtensionManager, create_iot_extension
    from extensions.app_deployment import AppDeploymentManager
    from extensions.role_switch import DeviceRoleManager, DeviceMode, DeviceCapabilities
    EXTENSIONS_AVAILABLE = True
except ImportError:
    EXTENSIONS_AVAILABLE = False
```

def switch_features_handler(self, ev):

## 6. 智能路径优化

### 6.1 基于应用类型的动态路由

**实现位置**: `ble_switch_13.py:_packet_in_handler()` 和 `_apply_optimized_routing()`

根据设备优先级和路由选择字段自动选择：
- **高优先级 (≥8)**: 低延迟专用路径
- **中优先级 (5-7)**: 标准路径
- **低优先级 (<5)**: 默认路径

路由选择类型：
- 类型 1: 低延迟路径
- 类型 2: 高带宽路径

## 7. 边缘计算功能

### 7.1 应用下发

**实现位置**: `switch/extensions/app_deployment.py`

#### 应用模型

```python
class EdgeApplication:
    def __init__(self, app_id, app_name, app_type, app_code,
                 version="1.0.0", description="", requirements=None):
        self.app_id = app_id
        self.app_name = app_name
        self.app_type = app_type
        self.app_code = app_code
        self.version = version
        self.description = description
        self.requirements = requirements or {}
        self.checksum = hashlib.sha256(self.app_code.encode()).hexdigest()
        self.status = AppStatus.NOT_DEPLOYED
        self.deployed_devices = []
```

#### 应用类型

| 枚举值 | 名称 | 说明 |
|--------|------|------|
| 1 | DATA_FILTER | 数据过滤 |
| 2 | AI_INFERENCE | AI推理 |
| 3 | DATA_AGGREGATION | 数据聚合 |
| 4 | CUSTOM | 自定义 |

#### 应用状态

| 枚举值 | 状态 |
|--------|------|
| 0 | NOT_DEPLOYED (未部署) |
| 1 | DEPLOYING (部署中) |
| 2 | RUNNING (运行中) |
| 3 | STOPPED (已停止) |
| 4 | ERROR (错误) |

#### 应用部署管理器

**创建应用**:

```python
app = self.app_deployment_manager.create_application(
    app_id="data_filter_001",
    app_name="数据过滤应用",
    app_type=AppType.DATA_FILTER,
    app_code="filter_data(data)",
    version="1.0.0",
    description="数据过滤应用"
)
```

**部署应用到设备**:

```python
result = self.app_deployment_manager.deploy_application(
    app_id="data_filter_001",
    device_id="iot3"
)
# 应用状态更新为 RUNNING，设备添加到 deployed_devices
```

**卸载应用**:

```python
result = self.app_deployment_manager.undeploy_application(
    app_id="data_filter_001",
    device_id="iot3"
)
# 从设备移除应用，如无其他部署则状态更新为 STOPPED
```

#### 控制器集成方法

| 方法 | 说明 |
|------|------|
| `create_edge_application()` | 创建边缘应用 |
| `deploy_application_to_device()` | 部署应用到设备 |
| `undeploy_application_from_device()` | 从设备卸载应用 |
| `list_edge_applications()` | 列出所有边缘应用 |

## 8. REST API 参考

### 拓扑 API

**GET/POST /api/topology**

```json
{
  "switches": [1, 2],
  "links": [{"src_switch": "switch-1", "src_port": 2, "dst_switch": "switch-2", "dst_port": 1}],
  "hosts": [{"mac": "00:00:00:00:00:01", "ip": "192.168.1.10", "switch_dpid": 1, "port": 1}],
  "timestamp": 1234567890.0
}
```

### 统计 API

**GET /api/stats**:

```json
{
  "port_stats": {"1": [{"port_no": 1, "rx_packets": 100, "tx_packets": 50}]},
  "flow_stats": {},
  "table_stats": {}
}
```

### 流表 API

**POST /api/flows** — 添加流表:

```json
{
  "dpid": 1,
  "table_id": 0,
  "priority": 100,
  "match": "eth_type=0x0800,ipv4_dst=192.168.1.20",
  "actions": "output:2"
}
```

**DELETE /api/flows** — 删除流表:

```json
{"dpid": 1, "table_id": 0}
```
