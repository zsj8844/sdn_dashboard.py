## 1. 测试环境

### 1.1 硬件环境
- 操作系统: Linux (Ubuntu 20.04 或更高版本) / Windows
- 内存: 至少 4GB RAM
- 硬盘: 至少 20GB 可用空间

### 1.2 软件环境
- Python 3.8+
- Ryu SDN 控制器框架
- Mininet 网络仿真器 (Linux)
- Open vSwitch 2.13+
- Flask Web 框架

### 1.3 依赖安装
```bash
# 使用自动脚本创建虚拟环境并安装依赖
chmod +x create_venv.sh
./create_venv.sh

# 激活虚拟环境
source .venv/bin/activate

# Linux 环境:
sudo apt-get install mininet openvswitch-switch
```

def infer(data):
    result = {'status': 'normal', 'confidence': 0.0}
    if 'sensor_data' in data:
        sensor_value = data['sensor_data']
        if sensor_value > 90:
            result['status'] = 'anomaly'
            result['confidence'] = 0.95
    return result

#### 数据聚合应用示例
```python
aggregated_data = {'values': [], 'count': 0}
def aggregate_data(data):
    global aggregated_data
    if 'value' in data:
        aggregated_data['values'].append(float(data['value']))
        aggregated_data['count'] += 1
    return {
        'count': aggregated_data['count'],
        'average': sum(aggregated_data['values']) / len(aggregated_data['values']) if aggregated_data['values'] else 0
    }
```
